# RiftDen: подготовка публичного релиза

Согласованный пользователем план из 20 пунктов. Реализация без изменения игровой концепции и визуальной системы HUD.

Порядок: проверки и контракты → устойчивость и производительность → SEO и содержание → доступность → проверка релиза и эксплуатация.

## Решения

- Сохранить npm workspaces и движок-подмодуль; изменения движка учитывать отдельно.
- Статичный текст и SEO остаются на сервере; большие данные интерактивного редактора загружаются отдельным запросом.
- Бюджеты: LCP ≤ 2500 мс, INP ≤ 200 мс, CLS ≤ 0,1 (75-й перцентиль реальных посещений); HTML главной ≤ 280 КиБ, билдов ≤ 100 КиБ без сжатия.
- Проверки release candidate обязательны перед публикацией. Внешние кабинеты и реальные Web Vitals нельзя считать завершёнными без доступа и наблюдений.
- Не запускать старый deploy.sh с git reset --hard: сохранить локальные изменения и предыдущий образ.

## Ограничения окружения

Проект root-owned. Обычному пользователю недоступен установленный Node; запускать проверки через sudo. Диск исчерпал место для обычного пользователя; не удалять чужие данные.
