# Rift Codex

Фан-сайт по League of Legends на русском и английском — [riftden.com](https://riftden.com): характеристики всех чемпионов с ростом по уровням 1–18, места в рейтингах, сравнение, умения с видео, образы, предметы, билды, карта Рунтерры. [Next.js](https://nextjs.org) 16 (App Router), все страницы собираются статически на каждом языке.

Дизайн-система «HUD» описана в [DESIGN.md](DESIGN.md), живая версия с компонентами — страница `/design` (только на русском, закрыта от поисковиков).

## Устройство

Репозиторий — общий движок и сайты игр (npm workspaces):

| Папка | Что там |
|---|---|
| `packages/engine` | Движок `@rift/engine` — git-подмодуль, репозиторий [Gildra-Foundation/core](https://github.com/Gildra-Foundation/core): интерфейс, шапка, подвал, поиск, языки, статьи на MDX, тир-лист, угадайка, базовые стили. Ничего не знает об игре |
| `apps/lol` | Сайт League of Legends: данные, формулы, тема, страницы, HUD чемпиона, дуэль |

Как сделать такой же сайт по другой игре, например по Genshin Impact, — в [docs/new-game.md](docs/new-game.md).

## Запуск

Движок подключён подмодулем, поэтому клонировать вместе с ним:

```bash
git clone --recurse-submodules https://github.com/Gildra-Foundation/LoL.git
```

Если репозиторий уже склонирован без подмодуля: `git submodule update --init`. Изменения движка коммитятся в `packages/engine` (репозиторий core), а в этом репозитории — новая ссылка на коммит движка.

Команды — из корня репозитория:

```bash
npm install
npm run dev       # разработка: http://localhost:3000
npm run build     # сборка: все страницы на русском и английском
npm run start     # запуск собранной версии
npm run check     # проверка типов движка и сайта
```

## Выкладка

Сайт работает на сервере в Docker: контейнер `riftden-web` (сборка по `Dockerfile`) и `riftden-nginx` с сертификатом Cloudflare Origin. Порты 80/443 на сервере заняты другим проектом, поэтому Cloudflare ходит на сервер по порту 8443 (правило Origin Rules в зоне riftden.com). Файлы — в `deploy/`:

- `deploy/deploy.sh` — на сервере: свежий код из GitHub, сборка образа, перезапуск;
- `deploy/compose.yml`, `deploy/nginx.conf` — контейнеры и nginx;
- `deploy/cloudflare.py` — сертификат Origin, DNS, строгий SSL и правило порта (ключ API берётся с сервера).

## Языки

Русский — основной язык: его адреса без префикса (`/champions`). Английский — с префиксом `/en` (`/en/champions`). Переключатель языка — в шапке.

- Маршруты лежат в `apps/lol/src/app/[lang]/`, адреса без префикса отдаёт `apps/lol/src/proxy.ts` (русская версия), а `/ru/…` перенаправляет на адрес без префикса.
- Строки интерфейса — рядом с компонентом: `const MESSAGES = defineMessages({ ru: {…}, en: {…} })`. На сервере `MESSAGES[lang]`, в клиентском компоненте `useMessages(MESSAGES)`.
- Ссылки — через `@rift/engine/i18n/Link`: он сам добавляет префикс языка, в коде адреса пишутся без него.
- Данные Riot (чемпионы, предметы, руны, регионы, лор) скачиваются на каждом языке в `apps/lol/src/data/<язык>/`; числа одинаковы, отличаются названия и тексты.
- Новый язык: добавить его в `LOCALES` (`packages/engine/i18n/locale.ts` и `apps/lol/scripts/locales.mjs`), перевести блоки `defineMessages` (TypeScript подскажет, где не хватает строк) и скачать данные.

## Разделы

| Адрес | Что там |
|---|---|
| `/` | Экран выбора чемпиона как в клиенте игры (фильтр по линии, умения, здоровье на 1 и 18 уровне), входы в разделы, рекорды патча, статьи |
| `/tier-list?lane=middle` | Конструктор тир-листа: тиры S–D для каждой линии, перетаскивание или клавиши; расстановка хранится в браузере, ссылкой можно поделиться |
| `/champions` | Каталог с поиском, фильтрами (класс, позиция, тип атаки и урона, сложность) и сортировкой; фильтры сохраняются в адресе |
| `/champions/<id>` | Страница чемпиона: HUD с полосками здоровья и ресурса, уровень 1–18, умения с видео (клавиши P Q W E R), таблица характеристик с местами и сравнением с классом, график роста, образы, подсказки, мини-карта позиций, стиль игры, история и связи: цитата, биография, родина, связанные чемпионы, рассказы |
| `/stats` | Лидеры, сортируемая таблица всех чемпионов, средние по классам, диаграмма |
| `/compare?a=garen&b=darius&level=11` | Синяя сторона против красной на любом уровне |
| `/duel?a=garen&b=darius&level=6` | Дуэль на автоатаках: живой бой с полосками здоровья и всплывающим уроном, разбор цифр, против кого чемпион выигрывает на этом уровне |
| `/runeterra?region=ionia` | Карта Рунтерры: выбор региона, камера подлетает к нему, панель с артом и видео региона, историей и чемпионами; линии связей чемпионов с другими регионами, путешествие по всем регионам |
| `/runeterra/ionia` | Страница региона: видео, история, галереи артов с просмотром, чемпионы с цитатами, связи с регионами, комиксы и рассказы, соседи по карте |
| `/items?item=3031` | Предметы как магазин в игре: разделы, фильтры по характеристикам, цена, эффекты, рецепт и улучшения |
| `/builds` | Конструктор билдов: чемпион и линия, руны, заклинания призывателя и предметы; итоговые характеристики на любом уровне, стоимость, ссылка на билд и сохранённые билды |
| `/guess` | Угадай чемпиона: загадка дня по признакам (класс, линия, ресурс, год…) или по кусочку арта, плюс тренировка |
| `/articles` | Статьи (пока пусто: сгенерированные статьи убраны в `archive/articles`, новые появятся из админки) |
| `/design` | Дизайн-система (только на русском) |

Поиск по сайту открывается по `Ctrl+K` или `/`. На странице чемпиона работают клавиши P Q W E R (на любой раскладке) и «+»/«−» для уровня. В тир-листе выбранный чемпион ставится в тир клавишами S A B C D (или 1–5), Delete возвращает его в список.

## Данные

```bash
npm run update-data
```

Скрипты `apps/lol/scripts/fetch-data.mjs` (чемпионы), `fetch-items.mjs` (предметы, руны, заклинания призывателя) и `fetch-regions.mjs` (регионы, галереи, лор и связи чемпионов из Universe) скачивают последний патч на всех языках сайта и сохраняют его в `apps/lol/src/data/<язык>/` (общий `meta.json` — версия патча и дата). После обновления пересоберите сайт.

- **Data Dragon** (официальный CDN Riot) — характеристики, умения, советы, образы.
- **CommunityDragon** — стиль игры, тип урона, редкость образов, видео умений. Из игровых файлов берутся прирост силы атаки и коэффициент скорости атаки: в Data Dragon с патча 16.5 прирост силы атаки у всех чемпионов ошибочно равен 0.
- **Meraki Analytics** — основные позиции и дата выхода.

Рост характеристик считается по официальной формуле: `база + прирост × (n − 1) × (0,7025 + 0,0175 × (n − 1))`. Формулы лежат в `apps/lol/src/lib/stats.ts`.

## Статьи

Статьи — MDX-файлы в `apps/lol/src/content/articles/<язык>/` (`ru` или `en`), у каждого языка свои. Пока их нет: раздел «Статьи» скрыт из меню и поиска и появится, как только в папке языка будет хотя бы одна статья. Пример заголовка файла:

```yaml
---
title: "Заголовок"
description: "Описание для карточки и поисковиков"
category: Механики        # ru: Механики | Макро | Новичкам | Аналитика; en: Mechanics | Macro | Beginners | Analytics
date: 2026-10-01
cover: { champion: Ahri, skin: 0 }   # обложка — сплэш-арт чемпиона
champions: [Ahri, Zed]               # блок «Чемпионы в статье»
featured: false                      # главная статья на главной и в журнале
---
```

В тексте можно использовать компоненты (импортировать не нужно):

- `<Callout type="tip" title="…">…</Callout>` — врезка (`tip`, `info`, `warning`);
- `<Champ id="Garen" />` — ссылка на чемпиона с иконкой;
- `<ChampionGrid ids={["Garen", "Annie"]} />` — сетка чемпионов;
- `<Formula caption="…">…</Formula>` — формула;
- `<StatLeaders stat="hp" level={18} limit={5} />` — рейтинг из актуальных данных.

Перед публикацией проверьте статьи: `npm run check-articles`. Скрипт проверяет frontmatter, синтаксис MDX и существование чемпионов.
